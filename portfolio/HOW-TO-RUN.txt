طريقة التشغيل على Windows
==========================

1) ثبّت Python 3 من: https://www.python.org/downloads/
   مهم جداً: أثناء التثبيت ضع علامة على "Add Python to PATH".

2) فك ضغط الملف (Extract All) — لا تشغّل من داخل الملف المضغوط مباشرة.

3) افتح مجلد portfolio وانقر نقراً مزدوجاً على: start.bat
   - إذا ظهرت رسالة Windows protected your PC: اضغط More info ثم Run anyway.
   - في المرة الأولى يثبّت المكتبات (يحتاج إنترنت) ويطلب إنشاء حساب المدير:
     اسم مستخدم + كلمة مرور 10 أحرف على الأقل (لا تظهر أثناء الكتابة).

4) يفتح الموقع تلقائياً:
   الموقع:        http://localhost:5000
   لوحة التحكم:   http://localhost:5000/admin

اترك النافذة السوداء مفتوحة أثناء الاستخدام. للإيقاف أغلقها.
إذا ظهر خطأ، صوّر النافذة السوداء وأرسلها.
